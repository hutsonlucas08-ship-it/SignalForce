Safety Rules & Metric Definitions

How SignalForge interprets incomplete evidence

Read-only
Missing critical risk fieldsInsufficient data
Single provider observedLimited evidence
Stale observationsReview required
Live order executionNot available

SignalForge currently provides research and risk context plus paper-trading simulation. It does not execute real trades or move funds. A clean screen is not a guarantee that a token is safe.

QUICK DEFINITIONS
Market capitalization (Market cap)
Estimated total token value at the current price.
FDV — Fully diluted valuation
Estimated value if all token supply were circulating.
Liquidity
Value available in trading pools; low liquidity can make exits difficult.
Buy / sell transactions
Transaction counts, not a count of unique buyers or sellers.
First recorded market cap
Earliest value stored by SignalForge; only equals launch market cap if collection began at launch.
Insufficient data
Required information is missing. It must never be interpreted as a safe result.
